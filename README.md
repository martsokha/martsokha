## Currently Working On

<img src="https://raw.githubusercontent.com/nvisycom/server/main/.github/assets/logo.png" alt="" width="20" height="20" /> **[Nvisy](https://github.com/nvisycom)**: an open-source platform for detecting
and redacting sensitive data in documents, images, and audio. It combines
pattern matching with ML models, and ships with SDKs and workflow integrations.

<img src="https://raw.githubusercontent.com/nvisycom/elide/main/.github/assets/logo.png" alt="" width="20" height="20" /> **[Elide](https://github.com/nvisycom/elide)**: a Rust library for building
redaction pipelines. Comes with built-in recognizers for common PII, and you can
add custom rules or plug in your own ML models.

<img src="https://raw.githubusercontent.com/spire-rs/spire/main/.github/assets/logo.png" alt="" width="20" height="20" /> **[Spire](https://github.com/spire-rs/spire)**: a Rust framework for web crawling
and scraping, influenced by Axum. You write async handlers, and it takes care of
routing, retries, deduplication, robots.txt, and per-host rate limits.
