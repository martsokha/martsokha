## Currently Working On

**[Nvisy](https://github.com/nvisycom)**: an open-source platform for detecting
and redacting sensitive data in documents, images, and audio. It combines
pattern matching with ML models, and ships with SDKs and workflow integrations.

**[Elide](https://github.com/nvisycom/elide)**: a Rust library for building
redaction pipelines. Comes with built-in recognizers for common PII, and you can
