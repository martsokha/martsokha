# Hello!

Backend systems · Data pipelines · Privacy tooling · Open source

## Currently Working On

**[Nvisy](https://github.com/nvisycom)**: an open-source platform for detecting
and redacting sensitive data in documents, images, and audio. It combines
pattern matching with ML models, and ships with SDKs and workflow integrations.

**[Elide](https://github.com/nvisycom/elide)**: the Rust library behind Nvisy's
redaction pipeline. It ships with built-in recognizers for common PII, and you
can add custom rules or plug in your own ML models.
[Read more →](https://martsokha.com/building-multimodal-redaction)

## Side Projects

**[Spire](https://github.com/spire-rs/spire)**: a Rust framework for web crawling
and scraping, influenced by Axum. You write async handlers, and it takes care of
routing, retries, deduplication, robots.txt, and per-host rate limits.
[Read more →](https://martsokha.com/write-handlers-not-scrapers)
