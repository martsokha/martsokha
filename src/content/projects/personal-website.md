# Personal Website

This is my personal website and portfolio, built with modern web technologies to showcase my projects, share my thoughts through blogging, and provide a professional online presence.

## Features

- **Fast & Modern**: Built with Astro for optimal performance and SEO
- **Responsive Design**: Works seamlessly across all devices
- **Blog Integration**: Content management with MDX support
- **Project Showcase**: Detailed project presentations
- **Dark Mode**: System-aware theme switching
- **Analytics**: Privacy-focused analytics integration

## Technical Implementation

The site leverages Astro's static site generation capabilities while incorporating modern development practices:

- **Type Safety**: Full TypeScript implementation
- **Component Architecture**: Reusable Astro and Vue components
- **Content Collections**: Organized content management system
- **Performance Optimization**: Image optimization and lazy loading
- **SEO Optimization**: Comprehensive meta tags and structured data

## Challenges & Solutions

One of the main challenges was creating a flexible layout system that could handle different content types while maintaining consistency. This was solved by implementing a hierarchical layout structure with `MinLayout` as the base and `Layout` extending it with additional components.
