# nvisy.com - Multimodal Redaction Platform

An open source platform that automatically identifies and redacts sensitive information across text, images, audio, and video content. Built for organizations that need to protect privacy while maintaining data utility for analysis and compliance.

## Core Capabilities

- **Text Redaction**: PII, PHI, financial data, and custom entity detection
- **Image Processing**: Face detection, license plate redaction, document sanitization
- **Audio Redaction**: Speech-to-text with selective content masking
- **Video Processing**: Real-time face tracking and audio track redaction
- **Batch Operations**: High-throughput processing for enterprise workflows
- **API Integration**: RESTful APIs for seamless system integration

## Technology Stack

- **Backend**: Python, FastAPI, Celery for async processing
- **Frontend**: TypeScript, React, TailwindCSS
- **ML/AI**: Transformers, OpenCV, Whisper, custom NLP models
- **Infrastructure**: Docker, Kubernetes, PostgreSQL, MinIO

## Use Cases

Organizations use nvisy for HIPAA-compliant medical records, legal discovery document processing, government classified content handling, and media source protection. The platform supports both cloud-hosted and self-hosted deployments.

## Compliance & Privacy

Built with GDPR, CCPA, and HIPAA compliance features, including configurable data retention policies, audit trails, and local processing options that ensure sensitive data never leaves your infrastructure.
